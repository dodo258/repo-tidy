## 有什么

- `repo-tidy [路径...]`：扫一个目录下所有 git 仓库，把每个附加 worktree 和本地分支分成「可删」（附证据：在默认分支哪个提交里 / 推到了哪个远程）和「留着」（附原因）。认普通合并、快进、squash、rebase 和模拟合并不再带来改动的分支。
- 每个仓库附一段体检：占用空间、未提交改动、stash、上游领先落后、最后提交、`backup` 远程是否推到最新（`--online` 联网查）。
- `--apply`：删前逐项重新判定，靠「已推到远程」的先联网确认，每一项先写恢复命令再删。
- `--json` 给脚本用；`--apply --select <文件|->` 只删挑出来的项。
- Mac App（`mac/`，SwiftUI）：点着看、勾着删，菜单栏显示可删总数。

---

First public release.

- `repo-tidy [paths...]` scans every git repository under a folder and sorts each extra worktree and local branch into *removable* (with evidence: the default-branch commit that contains it, or the remote ref it was pushed to) and *keep* (with the reason). Recognizes regular, fast-forward, squash and rebase merges, and branches whose simulated merge adds nothing.
- A per-repository health check: disk usage, uncommitted changes, stashes, ahead/behind upstream, last commit, and whether the `backup` remote is up to date.
- `--apply` re-checks every item before deleting, confirms pushed items online, and writes a restore command before each deletion.
- `--json` for scripts; `--apply --select <file|->` deletes only the items you pick.
- A SwiftUI Mac app in `mac/`.

Output is Chinese only for now. The Mac app is not signed or notarized yet, so no `.app` is attached; build it from source (see README).
