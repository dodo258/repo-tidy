## 新增

- **让 Claude Code、Codex 来清，又不让它自己想办法删**：README 第 4 节有一段贴进 `CLAUDE.md` / `AGENTS.md` 的提示（先列清单、你看过才删、用 `--select` 只删同意的、不许 `--force`），另有给 Claude Code 的 `permissions.deny` 三条。在演示仓库里用 Claude Code 试过，Codex 还没试。
- **崩掉的会话留下的锁不再挡着**：Claude Code 这类代理会把 worktree 锁成「claude session … (pid N)」，会话崩掉后锁还在。现在锁原因里的进程都已退出时，照没锁一样走完整判定，证据里注明锁已失效；`--apply` 先解锁再删，没删成按原来的原因锁回去。进程还在、或锁没写 pid 的照旧留着。
- **跳过不想碰的仓库**：`--exclude <路径>`（可以写多次）或环境变量 `REPO_TIDY_EXCLUDE`（冒号隔开）。跳过的不报告、不体检，`--apply` 也不删。
- **删完告诉你原来指向哪个提交**：终端、JSON 的 `message`、Mac App 的结果弹窗都写。
- **Mac App**：右栏可以切到「只看可删」、按名字或分支搜（⌘F）；worktree 可以按大小或最后活动时间排；设置里加「排除路径」，和 `--exclude` 一致。

## New

- **Let Claude Code or Codex clean up without improvising the deletion**: section 4 of the README has a prompt to paste into `CLAUDE.md` / `AGENTS.md` (list first, delete only after you have seen the list, delete only approved items with `--select`, never `--force`), plus three `permissions.deny` rules for Claude Code. Tried with Claude Code on demo repositories; not tried with Codex yet.
- **Locks left by crashed sessions no longer get in the way**: agents such as Claude Code lock their worktree as "claude session … (pid N)", and the lock stays behind when the session crashes. When every process named in the lock reason has exited, the worktree is now judged in full as if it weren't locked, and the evidence says the lock is stale; `--apply` unlocks it before deleting and locks it again with the same reason if the deletion fails. Locks whose process is still running, or that name no pid, are kept as before.
- **Skip repositories you don't want touched**: `--exclude <path>` (repeatable) or the `REPO_TIDY_EXCLUDE` environment variable (colon-separated). Skipped repositories are not reported or checked, and `--apply` won't delete anything in them.
- **Results say which commit each deleted item pointed to**: on the terminal, in the JSON `message`, and in the Mac app's results sheet.
- **Mac app**: switch the right pane to "Removable only" or filter by name or branch (⌘F); sort worktrees by size or last activity; "Excluded paths" in Settings, the same as `--exclude`.

## Fixed

- `--help` now documents `--select`.
- Mac app: repositories without a backup remote are no longer reported as "no backup remote"; when no repositories are found, the message says how many levels were searched and has an "Open Settings" button; changing the depth or folder during a scan triggers another scan when it finishes; the Settings field is aligned and its help text is no longer cut off; the restore log path in the results sheet is no longer cut off.

The Mac app is not signed or notarized yet, so no `.app` is attached; build it from source (see README).
