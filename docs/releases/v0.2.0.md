## 新增

- **正在用的 worktree 不动**：worktree 里有进程的工作目录（报告写出进程名和 pid），或 index、HEAD、reflog 在 `--min-idle`（默认 30 分钟）内动过，一律留着。代理在两次提交之间、提交又自动推到远程时，以前会被判成可删，现在不会了；`--apply` 删前也会现查一次。
- **撤销**：`repo-tidy --undo` 列出最近一次清理能恢复的项，`--undo --apply` 把分支和 worktree 建回原处；`--undo <日志>` 指定哪一次。Mac App 删除结果里有「撤销这次清理」。
- **英文输出**：按 `LC_ALL`/`LC_MESSAGES`/`LANG` 选中文或英文，`--lang zh|en` 指定；Mac App 跟系统语言。
- **报告短了**：可删项一行一个，行尾是证据的短形式；`--verbose` 看完整证据。
- **筛选**：`--older-than 30d`、`--only branches|worktrees`，筛掉的项不显示、`--apply` 也不删。
- **扫描深度**：`--depth N`（最多 4），给 `~/code/<组织>/<仓库>` 这种布局用。
- **默认分支认远程跟踪引用**：本地没有 main、只有 `origin/main` 的仓库也能判定。
- **备份远程可配置**：`--backup-remote <名字>`；仓库里没有这个远程就不提。
- **更快**：量大小和判定并行，少跑 git；扫描时在终端显示进度（`--progress` 给调用方用）。
- **Mac App 自带命令行**：打包时把 universal 的 `repo-tidy` 放进 App，不用另装。

## New

- **Worktrees in use are left alone**: a worktree that is some process's working directory (the report names the process and pid), or whose index, HEAD or reflog changed within `--min-idle` (default 30 minutes), is kept. An agent's worktree between commits, with its commits pushed automatically, used to be judged removable; it no longer is, and `--apply` checks again right before deleting.
- **Undo**: `repo-tidy --undo` lists what the last cleanup removed and can restore; `--undo --apply` recreates the branches and worktrees in place; `--undo <log>` picks a specific cleanup. The Mac app's results sheet has "Undo This Cleanup".
- **English output**: chosen from `LC_ALL`/`LC_MESSAGES`/`LANG`, or set with `--lang zh|en`; the Mac app follows the system language.
- **Shorter report**: one line per removable item with short evidence; `--verbose` for the full sentence.
- **Filters**: `--older-than 30d`, `--only branches|worktrees`; filtered-out items are hidden and never deleted by `--apply`.
- **Search depth**: `--depth N` (up to 4) for layouts like `~/code/<org>/<repo>`.
- **Default branch from remote-tracking refs**: repositories with only `origin/main` and no local `main` are judged too.
- **Configurable backup remote**: `--backup-remote <name>`; repositories without it skip that line.
- **Faster**: sizing and judging run in parallel with fewer git calls; progress is shown on the terminal while scanning (`--progress` for callers).
- **The Mac app bundles the CLI**: a universal `repo-tidy` is built into the app, no separate install.

The Mac app is not signed or notarized yet, so no `.app` is attached; build it from source (see README).
